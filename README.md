# Компьютер Пососони

Статическая копия опубликованного сайта, подготовлена 27.10.2026.

Все файлы этой папки загрузить в корень репозитория Neebywhoi/Pososonya-site.
Settings → Pages → Deploy from a branch → main → / (root) → Save.
Адрес: https://neebywhoi.github.io/Pososonya-site/

Работают папки, истории, фото, темы, обои, замок-загадка и локальные заметки.
Серверного редактора, загрузки фото, отправки заметок и автообновления ранга нет.
Истории можно править в published-content.js; исходные истории — в files.js.
Раздел «Личное» — игровая загадка, его содержимое публично доступно в файлах сайта.
Не загружайте сюда пароли, ключи и приватные серверные данные.
